<details open>
<summary><b>AI Solutions Specialist - CSTI Canada</b> - <i>Jul 2025 to Present</i></summary>

<br/>

Architect and lead all GenAI initiatives from use-case definition through production deployment, meeting enterprise security and scalability requirements. Driving the company-wide shift from hand-written code to agent-driven development, coaching engineers to direct AI coding agents and operate as solution architects.

- **Enterprise RAG Knowledge Platform** - Multi-tenant, on-premise GenAI platform serving 3 enterprise tenants and 100+ users across multiple countries. Hybrid dense + sparse retrieval (BGE-M3), reranking, anchored citations, multi-turn query rewriting, OCR ingestion, per-tenant multi-LLM selection. 10K+ documents indexed, ~500 ingested daily.
- **LLM Guardrails & Agentic Security** - Zero-authority LLM architecture with a deterministic 3-layer ACL enforced before and after every call, dynamic routing to specialized agents under capability-based authorization. Shipped via containerized CI/CD with full observability (Langfuse, OpenTelemetry).
- **Agentic AI Workflows** - Company-wide agent-driven development workflow: autonomous coding agents governed by bounded adversarial code-review gates and persistent cross-session memory over MCP.
- **Autonomous Contact Center Agents** - Turned traditional chatbots into AI agents handling 90% of customer contact volume autonomously, cutting contact center costs by 80%.
